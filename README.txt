GreenBasket — HTML/CSS/JavaScript only

Run: open index.html with VS Code Live Server.

Customer flow: auth.html -> register/login -> index.html customer dashboard -> shop/recipes/profile.
Admin flow: auth.html -> admin credentials -> admin.html.
Admin can add/delete shop products, add/delete recipes, publish notifications, and view order/sales/payment summaries.

Storage: Local Storage is used for users, login session, products, recipes, notifications, cart and orders.
